# SaparSplit

Приложение для планирования поездок и учёта общих расходов. Интерфейс собран на React, API работает на Node.js/Express, данные сохраняются в локальной SQLite-базе `db/saparsplit.db`.

Поездкой можно поделиться ссылкой-приглашением из раздела **Настройки поездки → Совместный доступ**. В локальном режиме можно войти без Google через демо-вход.

## Требования

- Node.js 22.12 или новее (SQLite входит в Node.js).

## Быстрый запуск

Клонируйте проект в Codespaces или на компьютер, откройте терминал в корне проекта и установите зависимости:

```sh
npm install
```

В первом терминале запустите API:

```sh
npm run dev:server
```

Во втором терминале запустите интерфейс:

```sh
npm run dev
```

В Codespaces откройте вкладку **Ports**, найдите порт `5173` и нажмите **Open in Browser**. На компьютере откройте `http://localhost:5173`.

SQLite-файл и таблицы создаются автоматически. Для локального запуска не нужны PostgreSQL, Docker, файл `.env`, Google Client ID или JWT secret. Секрет сессии генерируется при запуске сервера; после перезапуска сервера нужно войти снова.

Демо-вход использует общий аккаунт. В Codespaces оставьте доступ к порту приватным; этот режим предназначен для личного запуска и проверки.

## Вход через Google и production

Для Google-входа задайте `GOOGLE_CLIENT_ID` и `JWT_SECRET` в окружении сервера. В Google Cloud Console добавьте адрес сайта в **Authorized JavaScript origins**. В production оба значения обязательны, демо-вход отключён.

При необходимости путь к базе задаётся через `SQLITE_PATH`. Не добавляйте файлы `.env` или `db/saparsplit.db` в GitHub.
